

Prosty projekt demonstracyjny przedstawiający różne algorytmy sortowania zaimplementowane w języku C#, przy użyciu Windows Forms.

Projekt ma charakter edukacyjny i pozwala zrozumieć podstawowe metody sortowania danych.

---

##  Funkcje

- Implementacja podstawowych algorytmów sortowania
- Możliwość testowania działania algorytmów
- Przejrzysta prezentacja wyników
- Gnerowanie ciągów liczbowych na podstawie danynch wpisanych przez użytkownika
- 
##  Zastosowane algorytmy 

- Sortowanie Bąbelkowe
- Sortowanie przez Scalanie
- Sortowanie przez Wybór
- Sortowanie Szybkie
- Sortowanie Złożone
- Sortowanie przez Wstawianie
